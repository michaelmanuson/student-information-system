# Student Information System

## Overview

The Student Information System is a collaborative project developed by BSIT students to practice software development using Git and GitHub. The project focuses on understanding version control, branching, Pull Requests, and collaborative coding practices rather than building a complete information system.

---

## Objectives

- Learn Git and GitHub collaboration.
- Practice version control.
- Develop teamwork in software development.
- Understand branching and Pull Requests.

---

## GitHub Workflow

1. Clone the repository...
2. Create a personal branch.
3. Develop assigned tasks.
4. Stage changes using `git add .`
5. Commit changes.
6. Push the branch.
7. Create a Pull Request.
8. Leader reviews and merges.
9. Pull the latest updates.
